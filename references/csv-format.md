# CSV 书签样式规范（《csvtopdfbkmk》输入格式）

> 本文件是书签 CSV 的完整样式定义，与工作区 `AGENTS.md` 的"CSV 书签样式规范"一节同步维护。

CSV 用于描述 PDF 的分级书签，《csvtopdfbkmk》将其转换为福昕高级编辑器可导入的 XML。

## 列定义

第一行必须是表头，**三个列名一字不差**：

| 列名 | 类型 | 要求 |
| --- | --- | --- |
| `级别` | 正整数 | ≥ 1，`1` 为最高级；决定书签的层级与从属关系 |
| `标题` | 文本 | 非空，即书签显示的文字 |
| `物理页码` | 正整数 | ≥ 1，**PDF 物理页码**（文件第 1 页写作 `1`），不是印刷页码 |

- 列的先后顺序不限，但三列必须齐备；允许额外列（程序忽略）。
- 每行都必须有值，不允许空单元格。

## 编码

| 项目 | 要求 |
| --- | --- |
| 字符编码 | **UTF-8**（带不带 BOM 均可，程序按 `utf-8-sig` 读取）。建议带 BOM，Excel/WPS 双击打开不乱码；用 WPS/Excel 另存时选「CSV UTF-8」，不要选普通「CSV」 |
| 换行符 | CRLF / LF 均可 |
| 含逗号的标题 | 按标准 CSV 规则用双引号包裹，如 `1,"第1章 起步,概述",16` |

## 层级规则（栈算法，重点）

程序按栈逐行构建树：读到某级别时，先把级别 ≥ 它的节点全部弹出，再挂到当前栈顶之下。

| 规则 | 说明 |
| --- | --- |
| 行序 = 书签顺序 | 程序**不做排序**，必须按文档实际先后排列 |
| 级别可跨级回退 | `4 → 2` 合法（回到上一个 2 级之下） |
| 级别不可跳级推进 | `1 → 3` 虽不报错，但实际只有 2 层深度（3 级直接挂在 1 级下），应避免 |
| 级别数值不必连续 | 只用 `1` 和 `2` 也可以，只要相对大小关系正确 |
| 缩进由级别换算 | 导出时 `INDENT = 级别 − 1`，即 1 级对应 0 缩进 |

正确写法是**逐级递进**：`1 → 2 → 3`；回退时也回到真实存在的级别。

## 页码语义

- 填 **PDF 物理页码**：用 PDF 阅读器打开、翻到目标页，状态栏显示的页码（封面 = 1 起数）。
- **不是**书上印刷的页码；正文前有封面、目录、序言等未编号页面时，两者相差偏移量。
- 必须是正整数；`0`、负数、小数、空白都会被拦下。

## 校验报错对照

软件在选择文件后立即校验，通过时提示「共 N 条书签，最大层级 M」；失败弹窗报错。
报错行号从 **2** 开始（第 1 行为表头）。

| 报错信息 | 原因 |
| --- | --- |
| `缺少必填字段: 物理页码` | 表头写成了「页码」「页数」「page」等，或有全角字符、多余空格 |
| `第 N 行「级别」为空`（标题/物理页码同理） | 对应单元格没填 |
| `第 N 行「级别」值无效: 一` | 中文数字、小数或文本 |
| `第 N 行「物理页码」值无效: 0` | 页码为 0、负数或非数字 |
| `CSV 中没有数据行` / `CSV 文件为空` | 只有表头 / 空文件 |

实现细节（源自 converter.py 源码，用于排错判断）：

- 读取用 `encoding="utf-8-sig"`、`csv.DictReader`；表头校验用**集合差**（额外列允许、列顺序无关、列名必须完全一致）。
- 校验前对每个单元格做 `.strip()`；标题在建树时也会 strip。
- 已知宽限：全角数字"１"能被 `int()` 接受；`"01"`、`"+2"` 也通过。页码无单调性校验、不与 PDF 实际页数比对——这两项由本 skill 的脚本补查（警告）。
- 级别跳级（如 `1 → 3`）不报错，但生成的 XML 缩进会出现 0→2 跳变，且 pymupdf 直写路径会拒绝——务必逐级递进。

## 完整示例

```csv
级别,标题,物理页码
1,第一部分 基础知识,15
2,第1章 起步,16
3,1.1 搭建编程环境,17
4,1.1.1 Python版本,17
2,第2章 变量和简单数据类型,30
3,2.1 运行 hello_world.py,31
1,第二部分 进阶,88
```

## 填写提示

- 标题里**不要**带手动缩进或「├─」等符号，层级完全由 `级别` 列决定。
- 标题与 PDF 中显示的标题汉字完全一致，便于日后检索。二级标题常用格式 `N. 标题`（节号后半角点 + 空格），同一批书签内保持统一；标题中的全角冒号（如"实验：……"）、破折号按原书保留。
- 标题含 `&`、`<`、`>`、`"` 时**程序自动转义**，CSV 按原文填写；**不要**手写 `&amp;` 等 XML 实体，否则会显示成字面的 `&amp;`。
- 页码尽量从小往大排；程序不校验单调性，但顺序错乱会让书签列表出现回跳。
- 不确定页码时，先在 PDF 阅读器中确认再填写，页码错误会导致导入后跳转位置不对。

## 本 skill 的中间格式 titles.txt

模型转录后先写 `titles.txt`（每行一条，竖线分隔，`#` 为注释，空行忽略）：

```
1|第五章 抛体运动|4
2|1. 曲线运动|5
```

`scripts/bookmarks.py export/write` 均接受 titles.txt 或现成 CSV；两种输入最终归一为
`(级别, 标题, 物理页码)` 三元组序列后再校验、导出。
